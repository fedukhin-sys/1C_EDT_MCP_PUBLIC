# edt-mcp skill

Claude Code-скилл для работы с MCP-сервером **EDT_MCP** (плагин 1C:EDT, **91 инструмент**, v1.16.0).

## Что это

EDT_MCP — это OSGi-плагин для 1C:Enterprise Development Tools, который экспортирует HTTP+SSE MCP-сервер с 91 инструментом для:
- управления workspace/проектами;
- создания и редактирования метаданных 1С (Справочники, Документы, Регистры, Отчёты, СКД и т.д.);
- внешних объектов (внешние обработки/отчёты) и генерации печатных форм `.mxlx`;
- работы с BSL-модулями (read/write/list_methods/get_method);
- проверки качества (EDT-маркеры, SSL-чеки);
- управления инфобазами + деплой;
- журнала регистрации (`.lgf`/`.lgp`, file и server ИБ);
- запуска/остановки клиентов 1С (тонкий/толстый);
- отладки BSL (breakpoints, stack, evaluate);
- xUnitFor1C-тестов (create_test_module, run_tests).

Подробно: [GitHub `fedukhin-sys/EDT_MCP`](https://github.com/fedukhin-sys/EDT_MCP).

## Когда срабатывает

Используй этот скилл (или просто читай `SKILL.md`) когда нужно:
- создать/изменить объекты конфигурации 1С через MCP;
- сгенерировать форму, обработчики, СКД-отчёт;
- развернуть расширение на инфобазу;
- запросить события журнала регистрации;
- запустить тесты, отладку, клиента;
- сверить актуальную сигнатуру конкретного tool'а перед вызовом.

## Содержимое

- `SKILL.md` — полный reference: точные имена параметров всех 91 tools, рецепты типовых задач, smoke-харнес, главные правила работы, одно известное ограничение EDT-редактора.

## Источник

Скилл собран на основе прохождения test-plan'а в EDT 2026.1 с runtime 8.3.27. Версия MCP: **v1.16.0** (91 tools).

Если в вашем проекте версия отличается — сверьтесь с `tools/list`, имена/наборы инструментов могли поменяться.
