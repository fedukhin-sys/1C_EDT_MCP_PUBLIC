# edt-mcp skill

Claude Code-скилл для работы с MCP-сервером **EDT_MCP** (плагин 1C:EDT). Актуальный счётчик инструментов и версия — в `SKILL.md`.

## Что это

EDT_MCP — это OSGi-плагин для 1C:Enterprise Development Tools, который экспортирует HTTP+SSE MCP-сервер с инструментами для:
- управления workspace/проектами;
- создания и редактирования метаданных 1С (Справочники, Документы, Регистры, Отчёты, СКД и т.д.);
- внешних объектов (внешние обработки/отчёты) и генерации печатных форм `.mxlx`;
- работы с BSL-модулями (read/write/list_methods/get_method);
- проверки качества (EDT-маркеры, SSL-чеки);
- управления инфобазами + деплой;
- журнала регистрации (`.lgf`/`.lgp`, file и server ИБ);
- запуска/остановки клиентов 1С (тонкий/толстый);
- отладки BSL (breakpoints, stack, evaluate);
- xUnitFor1C-тестов (create_test_module, run_tests);
- обезличивания ПДн 152-ФЗ (fail-closed слой + 4 privacy-инструмента).

Подробно: [GitHub `fedukhin-sys/1C_EDT_MCP_PUBLIC`](https://github.com/fedukhin-sys/1C_EDT_MCP_PUBLIC).

## Когда срабатывает

Используй этот скилл (или просто читай `SKILL.md`) когда нужно:
- создать/изменить объекты конфигурации 1С через MCP;
- сгенерировать форму, обработчики, СКД-отчёт;
- развернуть расширение на инфобазу;
- запросить события журнала регистрации;
- запустить тесты, отладку, клиента;
- сверить актуальную сигнатуру конкретного tool'а перед вызовом.

## Содержимое

- `SKILL.md` — точка входа: подключение, архитектурные допущения, рецепты типовых задач, главные правила работы, «что НЕ работает».
- `references/tools.md` — полная таблица инструментов с точными именами аргументов и тип-выражениями.
- `references/1c-gotchas.md` — проверенные грабли BSL/1С из боевых задач.
- `references/1c-standards.md` — доводка созданных объектов до стандартов 1С (чистый проход `check_run`).
- `references/smoke-harness.md` — минимальный JS-клиент MCP для smoke-проверок.
