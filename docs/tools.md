# Список MCP-инструментов EDT_MCP

Сгенерировано из кода (`*Tool.java`, методы `name()` / `description()`).
Всего реализовано **84 инструмента**, сгруппированных по 10 bundle'ам.

|---|---|---|
| `tools.edt` | Workspace и проекты | 8 |

| `tools.debug` | Отладка BSL | 14 |
| `tools.quality` | Проверки качества кода | 4 |
| `tools.md` | Редактирование метаданных | 26 |
| `tools.form` | Формы | 11 |

## Workspace и проекты (`tools.edt`, 8)

| Инструмент | Описание |
|---|---|
| `list_projects` | Список открытых проектов 1С в workspace. |
| `get_workspace_info` | Корень workspace, счётчики проектов и зарегистрированные версии платформы 1С. |
| `list_runtime_versions` | Список версий платформы 1С, зарегистрированных в IDE. |
| `get_project` | Детали проекта по имени: тип, расположение, версия, признак открытости. |
| `list_project_files` | Список файлов и папок проекта (только пути, без содержимого). |
| `open_project` | Открыть проект в workspace (идемпотентно). |
| `close_project` | Закрыть проект в workspace (идемпотентно). |
| `create_project` | Создать новый проект 1С: конфигурация, расширение или внешний объект. |

## Модули BSL (`tools.bsl`, 5)

| Инструмент | Описание |
|---|---|
| `read_module` | Прочитать полный текст модуля BSL. |
| `write_module` | Записать содержимое модуля BSL (с опциональной проверкой синтаксиса перед записью). |
| `get_module_info` | Тип модуля, кодировка и количество методов. |
| `list_module_methods` | Список процедур и функций модуля с позициями (строки начала/конца, признак экспорта). |
| `get_method` | Текст и метаданные конкретной процедуры или функции модуля. |

## Информационные базы и развёртывание (`tools.infobase`, 5)

| Инструмент | Описание |
|---|---|
| `list_infobases` | Список информационных баз, зарегистрированных в 1C:EDT (с фильтром по папке/типу). |
| `get_infobase` | Детали информационной базы по имени или uuid. |
| `create_infobase` | Создать файловую ИБ через `1cv8.exe` и зарегистрировать её в 1C:EDT. |
| `associate_infobase` | Связать проект с информационной базой (опционально как основную). |
| `deploy_project` | Обновить конфигурацию ИБ из проекта (синхронизация проект → ИБ). |

## Запуск клиента 1С (`tools.client`, 3)

| Инструмент | Описание |
|---|---|
| `run_client` | Запустить тонкий или толстый клиент 1С для информационной базы. |
| `list_running_clients` | Список запущенных сеансов клиента 1С (с фильтром по ИБ/типу клиента). |
| `stop_client` | Остановить сеанс клиента по `sessionId` (мягко → принудительно по таймауту). |

| `evaluate` | Вычислить выражение BSL в кадре приостановленного сеанса. |

## Проверки качества кода (`tools.quality`, 4)

## Каркас тестов xUnitFor1C (`tools.tests`, 4)

| Инструмент | Описание |
|---|---|
| `list_test_modules` | Список общих модулей проекта, являющихся тестовыми модулями xUnitFor1C. |

## Запуск тестов xUnit (`tools.testrun`, 4)

| Инструмент | Описание |
|---|---|
| `install_test_runner` | Развернуть модули раннера тестов xUnit + обработчик `ПриНачалеРаботыСистемы`. |
| `uninstall_test_runner` | Удалить обвязку раннера тестов xUnit. |
| `run_tests` | Запустить тесты xUnit в модуле (или всех модулях) на развёрнутой ИБ. |
| `run_test_method` | Запустить один тестовый метод xUnit на развёрнутой ИБ. |
